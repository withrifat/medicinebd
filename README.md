# MedicineBD Dataset

MedicineBD is an open dataset of Bangladesh medicine information, available in both JSON and CSV formats.

## What is included

- `medicines.json` — structured JSON data
- `medicines.csv` — spreadsheet-friendly CSV data
- ~20k medicine records
- Price field included and editable

## Data fields

Each record includes core medicine details such as:

- medicine name
- category
- generic name
- strength
- manufacturer
- unit / pack size
- price (BDT)

## Usage

You can use this dataset for:

- data analysis and dashboards
- research and educational projects
- application development

## Editing the price

Prices can be updated directly in both files:

- In `medicines.csv`, edit the `price` column.
- In `medicines.json`, edit the `price_bdt` value.
